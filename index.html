How this works

  • Real dollars. Historical nominal returns (S&P 500 with dividends, 10-year Treasuries) are deflated by that year's CPI, so every figure here is in today's purchasing power and you never enter an inflation guess.
  • Each year: contribute (before retirement) or withdraw spending minus other income (after), then apply that year's portfolio return minus fees. A path fails when a withdrawal can't be covered.
  • Bootstrap draws random historical years independently. Block bootstrap draws 5-year runs, preserving streaks like 1929–33 or 1995–99. Every historical sequence starts one path in each year 1928–2024 (wrapping), the classic "would this have survived history" test — it has only 97 paths, so the percentiles are coarse. Normal is a parametric model with the mean and volatility you choose.
  • Sensitivity re-runs the full simulation with the same random draws and one input nudged, so differences are due to the input, not noise.
  • Not financial advice. Taxes, Social Security rules, healthcare shocks, and your actual fund choices are all outside this model.

Data: Aswath Damodaran (NYU Stern) annual returns 1928–2024; CPI-U annual averages from the Federal Reserve Bank of Minneapolis.
